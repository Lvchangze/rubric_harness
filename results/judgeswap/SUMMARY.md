# Judge-swap replication — does "agentic rubrics are better" survive a different judge?

**Snapshot of the source repo:** `2026-08-28T02:38:41Z` (rsync from
`/apdcephfs_zwfy6/share_302970870/hunyuan/changzelv/dev/rubric_harness`, excluding
`runs/cache/` and `__pycache__/`). Nothing was written back to the original repo.

## The threat being tested

The `agentic` rubrics were generated by `hy-t2t-glm-5.2-384k-fp8-L20A-t1-v2`, and the
pilot judged them with that same model. Their advantage could therefore reflect a shared
idiosyncrasy — phrasing that happens to suit that judge — rather than better criteria.
`baseline` controls for "same model + the paper's prompt" but not for judge/generator
sharing a model.

## Design

Only the judge changes. Rubrics (all six sources) and the degraded response ladder are
reused byte-for-byte from `runs/pilot_v2` (hard-linked, SHA-256 recorded in
`runs/judgeswap/judgeswap_manifest.json`). Judge prompt, `paper_explicit` aggregation,
polarity handling, comparator handling and the criterion-shuffle seed (7) are unchanged.

Questions were drawn from the pilot's own paired queue — the 151 questions with a
complete ladder under all six sources — and balanced to 57 science + 57 medicine, so
every comparison against the original is **paired on the same question**.

Four runs, three of them controls:

| run | judge | purpose |
|---|---|---|
| `runs/judgeswap` | `api_azure_openai_gpt-5.1` | the swap |
| `runs/oldjudge_sub` | incumbent (pilot rows, subset) | the published numbers on this question set |
| `runs/oldjudge_rerun` | incumbent, fresh sample, seed 7 | within-judge floor + per-criterion verdicts |
| `runs/oldjudge_retest` | incumbent, fresh sample, seed 8 | criterion-level within-judge floor |

The control runs matter: cross-judge agreement is uninterpretable without knowing how
well the incumbent agrees with *itself* on each source.

## 1. Judge selection and smoke test

Five different-vendor candidates were probed with the real judge prompt on real pilot
rubrics. `api_ali_glm-5.2` was deliberately **not** used: it is the same GLM-5.2 family
as the incumbent, only a different serving path.

| candidate | result | raw return type | latency |
|---|---|---|---|
| `api_azure_openai_gpt-5.1` | **works, selected** | `str` | 15.3 s/call |
| `api_azure_openai_gpt-5.6-sol` | works | `str` | 3.4 s/call |
| `api_ali_qwen3.8-max` | works | `dict` | 43.6 s/call |
| `api_aws_third_anthropic.claude-opus-5` | fails — budget ¥0 | — | — |
| `api_moonshot_kimi-k3` | fails — budget ¥0 | — | — |

`harness.llm.extract_response_text` handled both return shapes correctly (verified
against the raw client, not just through the wrapper). Cache keys include the model, so
the near-identical smoke scores across candidates were genuine agreement on easy
fixtures, not cache collisions (`cache_hits=0`, `api_calls=4` for each).

**Production run:** 4788 judgements, **0 failures**, 32 empty responses auto-escalated
and recovered, 14 JSON repairs. 5 cells (0.10%) were lost to LaTeX backslash escapes in
the judge's `why` field breaking JSON — spread across `baseline` (2),
`agentic-goldonly` (2) and `shipped` (1), i.e. source-neutral. Those 5 questions drop
from the paired analysis, giving **n=109 (52 science, 57 medicine)**.

## 3. Did the effect change? (judge × source interaction)

Because both judges scored the same questions, "did the effect shrink" is testable
directly rather than by eyeballing two CIs:

`DiD_q = (new_source_q − new_baseline_q) − (old_source_q − old_baseline_q)`

For `agentic`, without-gold, all 109 questions:

| metric | edge OLD | edge NEW | DiD | 95% CI | p |
|---|---|---|---|---|---|
| ranking_accuracy | +0.022 | +0.020 | −0.002 | [−0.019, +0.015] | 0.86 |
| auc | +0.043 | +0.052 | +0.009 | [−0.013, +0.032] | 0.47 |
| separation | +0.077 | +0.062 | −0.015 | [−0.039, +0.008] | 0.21 |
| z_separation | +0.187 | +0.209 | +0.022 | [−0.044, +0.086] | 0.52 |

Every interaction CI contains zero. The agentic advantage is **statistically
indistinguishable between the two judges**.

The one exception is `spread` (dynamic range, not discrimination): DiD −0.049, p=0.004.
gpt-5.1 compresses the score range of every agentic-family rubric — `agentic-noval`
moves most (−0.059), so this is a family-wide scale effect, not something specific to
the source that shares a model with the incumbent.

`agentic-goldonly` actually gains under the new judge (auc DiD +0.037, q=0.026).

## 4. Domain contrast — reproduced

The original's hardest claim was that `z_separation` improves in science and not in
medicine. Without-gold, `agentic` vs `baseline`:

| | OLD judge | NEW judge |
|---|---|---|
| science (n=52) | **+0.320** (p=0.0039) | **+0.340** (p=0.0013) |
| medicine (n=57) | +0.066 (p=0.18) | +0.088 (p=0.13) |
| science − medicine gap | +0.254, CI [+0.034,+0.481], p=0.028 | +0.252, CI [+0.027,+0.478], p=0.030 |

The domain asymmetry is judge-independent. Note the medicine null is now measured on 57
questions rather than 94, so it has less power than the original — but the point
estimate is unchanged and still small.

## 5. Head-to-head — **not** flipped

Position-bias corrected (a rubric wins only if it wins in both slot orders), same 114
questions for both judges. Global position bias itself reversed direction (old 0.535
first-slot, new 0.431), which is exactly what the two-order correction absorbs.

| pair | judge | win_A | win_B | B−A | shift | sign |
|---|---|---|---|---|---|---|
| baseline vs agentic | old | 0.456 | 0.254 | −0.202 | | |
| | new | 0.430 | 0.298 | −0.132 | +0.070, CI [−0.088,+0.228], p=0.46 | **unchanged** |
| shipped vs agentic | old | 0.114 | 0.781 | +0.667 | | |
| | new | 0.132 | 0.737 | +0.605 | −0.061, p=0.44 | unchanged |
| baseline vs agentic-noval | old | 0.254 | 0.456 | +0.202 | | |
| | new | 0.386 | 0.272 | −0.114 | −0.316, p=0.0005 | **FLIPPED** |

The counter-intuitive result — a judge preferring `baseline` to `agentic` in blind
pairwise comparison while every discriminative metric says the opposite — **replicates
under a different-family judge**. It is a real property of asking an LLM "which rubric
looks better", not an incumbent-judge artefact. Per-question agreement between the two
judges on this pair is only 0.491, so they disagree case by case while landing on the
same aggregate preference.

The `agentic-noval` preference, by contrast, *was* judge-specific.

## 6. Cross-judge agreement by source — the self-preference test

Raw cross-judge agreement is indeed highest for `baseline`, which taken alone would look
like self-preference. It is not, because the incumbent agrees with **itself** in the same
order — sources differ in how reproducibly they can be judged at all.

Score level, at (question, source, response):

| source | cross-judge r | within-judge r | gap |
|---|---|---|---|
| shipped | 0.919 | 0.941 | −0.021 |
| baseline | 0.953 | 0.977 | −0.024 |
| agentic-noval | 0.923 | 0.958 | −0.036 |
| **agentic** | **0.942** | **0.967** | **−0.025** |
| agentic-goldonly | 0.944 | 0.969 | −0.025 |
| agentic-negonly | 0.934 | 0.966 | −0.033 |

Per-criterion level (49.6k verdicts joined on the unshuffled criterion index):

| source | cross-judge agreement | within-judge agreement | gap |
|---|---|---|---|
| shipped | 0.907 | 0.928 | −0.022 |
| baseline | 0.941 | 0.961 | −0.020 |
| agentic-noval | 0.928 | 0.946 | −0.019 |
| **agentic** | **0.929** | **0.952** | **−0.022** |
| agentic-goldonly | 0.929 | 0.950 | −0.022 |
| agentic-negonly | 0.935 | 0.950 | −0.015 |

Paired by question, `agentic` vs `baseline`, on the judge-attributable gap:

| level | metric | Δ | 95% CI | p | q(BH) |
|---|---|---|---|---|---|
| score | mean abs diff | −0.000 | [−0.010, +0.010] | 0.94 | 0.94 |
| score | rank agreement | **+0.021** | [+0.003, +0.041] | 0.030 | 0.080 |
| score | min criterion disagreement | −0.001 | [−0.011, +0.009] | 0.88 | 0.92 |
| criterion | agreement | −0.002 | [−0.012, +0.008] | 0.68 | 0.79 |

The judge swap costs every source the same ~2 points of agreement. On the measure that
actually matters for a reward signal — whether the two judges *order* a question's
responses the same way — `agentic` degrades **less** than `baseline`, the opposite of
what self-preference predicts.

Caveat: the criterion-level floor uses shuffle_seed 8, so it also absorbs order
sensitivity that the cross-judge comparison (both judges at seed 7) does not have. That
makes it a conservative floor, i.e. it understates the cross-judge gap rather than
flattering it. The score-level floor has no such issue — it is same-seed resampling.

## 7. Verdict

**The conclusion is unchanged, and marginally strengthened.** Under a different-vendor,
different-family judge the agentic advantage is the same size (all interaction CIs
contain zero), survives gold exclusion, and shows the same science-only domain profile.

**No evidence of self-preference was found.** The one pattern that superficially looked
like it — `baseline` agreeing best across judges — disappears once the within-judge floor
is subtracted, and reverses on rank agreement.

Three honest caveats.

First, the **ranking among the ablations is not stable across judges**, even though the
headline `agentic` vs `baseline` effect is. Under the incumbent, `agentic` edges out
`agentic-goldonly` on ranking accuracy, AUC and z_separation; under gpt-5.1 the order
reverses on all three (e.g. without-gold z_separation: agentic +0.209 vs goldonly +0.226).
The main claim is robust; fine-grained statements about *which* agentic variant is best
are not, and should not be made on one judge.

Second, the head-to-head preference for `baseline` is real and replicates. The
discriminative and preference families genuinely disagree, and the swap has now ruled out
"the judge did it" as the explanation.

Third, medicine's null is measured on 57 questions here versus 94 in the original, so
this run is less able to detect a small medicine effect than the original was. The
science-vs-medicine *contrast* is significant under both judges, but "medicine is exactly
zero" is not what the data show — only that it is small and not detectable at this n.

## Not run

Transfer / specificity LLM metrics (the user's priority 4) were skipped for budget.
Zero-LLM structural metrics were skipped by design — a judge swap cannot move them.
